# 📊 Data Jobs Salary Dashboard (Power BI)

This project presents an **interactive Power BI dashboard** analyzing global **data-related job salaries**, including roles such as **Data Analyst, Data Scientist, Data Engineer, Cloud Engineer, and Software Engineer**.

## 🚀 Project Overview

The goal of this project is to explore the **data job market** and visualize:

- Salary distribution across different job roles  
- Hourly vs yearly salary comparisons  
- Remote work (WFH) availability  
- Health insurance coverage  
- Jobs that do not require a degree  
- Global job distribution by country  

This dashboard allows users to **interactively explore job market insights**.

## 📈 Dashboard Features

The Power BI dashboard includes multiple report pages.

### 1️⃣ Data Jobs Dashboard

Provides an overview of:

- Median yearly salary by job title  
- Salary comparison across roles  
- Job demand analysis  

### 2️⃣ Job Title Drill Through

Detailed view of a selected job role showing:

- Salary trends  
- Job counts  
- Hourly vs yearly salary  
- Job benefits and requirements

## 📊 Key Insights

Some insights from the analysis:

- **Data Scientists and Data Engineers** tend to have the highest median salaries  
- **Cloud Engineers and Software Engineers** also show strong salary growth  
- A significant portion of jobs **do not explicitly require a degree**  
- Remote work availability varies across different job roles
